# Pháo Hoa · Đón Giao Thừa

Trình diễn pháo hoa giao thừa — mở `index.html` hoặc publish GitHub Pages.

## Xem nhanh

Mở file `index.html` bằng trình duyệt, hoặc:

```bash
npx serve .
```

## Đưa lên GitHub Pages

```bash
git init
git add .
git commit -m "Add New Year fireworks show"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

Trong repo trên GitHub: **Settings → Pages → Source: Deploy from branch `main` / root**.

Link chia sẻ sẽ dạng: `https://<username>.github.io/<repo>/`
